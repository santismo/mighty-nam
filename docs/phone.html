MIGHTY PLUG PRO · A2 LITE · 48 KHZ

Your iPhone controller

Bluefy connects the web page to your plug. A Home Screen shortcut gets you there in one tap.

1. Install Bluefy

Get Bluefy — Web BLE Browser by PNN SOFT. The App Store currently lists it as free. Enable Bluetooth and allow Bluefy to use it.

Open this address inside Bluefy:

https://santismo.github.io/mighty-nam-controller/
Open in Bluefy ↗Open controller

The app-launch link needs an iPhone check. If it does not open the page, paste the HTTPS address into Bluefy and bookmark it.

2. Connect the plug

  1. Power on normally. Blinking-blue updater mode is not the controller mode.
  2. Disconnect the Mac app and other Bluetooth controllers.
  3. Tap Connect on the page and select your Mighty Plug Pro. Its Bluetooth name can still be the manufacturer’s name.
  4. Wait for Ready. Select a color or block to edit it. Save to plug only when you want the changes stored.

Usually no pairing in iOS Settings is needed: the page opens the device picker. See Bluefy’s connection guide. Safari Home Screen web apps do not replace Bluefy’s Bluetooth support.

3. Add mighty nam to your Home Screen

Download iPhone shortcut ↓Download icon ↓
  1. Install Bluefy first, then download and open mighty nam.shortcut on your iPhone. If the browser saves it to Files, open it there. Add it to Apple Shortcuts.
  2. Run mighty nam once. Allow it to open Bluefy if asked.
  3. In Shortcuts, open its name menu or details → Add to Home Screen.
  4. Tap the icon → Choose File and select the downloaded M-NAM PNG. Keep the name mighty nam, then tap Add.

The launcher is signed for sharing with anyone and contains only URL + Open URLs actions. iOS requires you to add the Home Screen icon yourself; downloading a shortcut cannot silently install it. Launching Bluefy from this file still needs an iPhone check.

Manual setup

Create a shortcut named mighty nam with a URL action followed by Open URLs. Use:

bluefy://open?url=https%3A%2F%2Fsantismo.github.io%2Fmighty-nam-controller%2F

If your Bluefy version does not handle the launch link, bookmark the controller inside Bluefy and use Open App → Bluefy instead.

4. Browse TONE3000

Open Captures → Browse TONE3000, sign in, and select a tone. Load its compatible 48 kHz A2 Lite model. The picker opens in a separate tab so the controller stays open. Select a capture, return to the controller and load its A2 Lite model. It keeps the connection where iOS permits, or attempts to reconnect to the same plug if the phone suspended it. If iOS denies that reconnect, tap Connect. Wait for confirmation that the capture is active. The capture browser stays open. Star multiple favorites; Save to plug separately stores the selected capture with a color.

Keep the page open during transfer or saving. Phone favorites are local, not TONE3000 account favorites. Clearing browser data removes local downloads; it does not erase onboard presets.

Tuner and buffer

Open Tuner and pluck one string. Note detection runs on the plug; Bluetooth reporting adds time. Close the tuner to return to playing. Buffer choices are confirmed by the device and save globally on NAMLNK18+. Lower buffering does not remove the delay inherent in pitch or modulation effects.

Looper

NAMLNK28 adds saved threshold, level and duration, and direct preset-back and overdub gestures. Open Looper to arm, finish, pause, resume, overdub or clear. The input meter is drawn on the threshold slider. New settings use −50 dB and 100% loop level; level can be lowered. Save looper settings stores changes across power-off after the retained loop is cleared. Loops themselves are not saved.

Use any of seven colors. Tap an empty color to save the current capture there, or choose Save to plug and select a destination. A retained loop must be cleared before writing presets; switching existing presets and live edits remain available.
