Get the NUX firmware

  1. Open the official Mighty Plug Pro product page ↗. Go to Support → Firmwares.
  2. Download V3.0.5 for macOS from NUX ↓. This ZIP contains the verified Original file and can be extracted on other computers too. Choose the Original image, not MP3_CT_V3.0.5.bin (ChopTones), another version, or firmware for a Mighty Plug without “Pro.”
  3. Extract the package on your computer. Install NUX Device Updater from the included NUX Device Updater 2.2.1.dmg. Select MP3_OR_V3.0.5.bin above, not the ZIP or updater. The builder checks the file contents, not just its name.

Install with the NUX updater

  1. Save the generated firmware and build report. Keep your original NUX file. Installation replaces all seven onboard preset slots and global settings, so export any presets you want to keep first.
  2. Verify that the device is a Mighty Plug Pro. Unplug headphones and connect a USB data cable. Close other plug controllers.
  3. Power off, then hold PRESET while powering on. In blinking-blue update mode, open NUX Device Updater and choose mighty-nam-NAMLNK28-experimental.bin with Select File….
  4. Click Start Update. Keep USB connected. Wait for explicit success before touching POWER or RESET. Then restart with POWER only, without PRESET.
  5. Open the Mac app or phone controller in normal mode. Check the NAMLNK28 identity and Green, Orange and Red starter presets. Keep the headphone volume low for first listening.
  6. PRESET cycles the three occupied colors. To save another: choose a color, load an A2 Lite capture, edit its effects and Save to plug. Verify your saved colors after restarting.

Payload provenance · How the builder works

Looper preview

Includes Daisy-derived Auto Wah, 30-second recording, optional lower-bandwidth 60-second recording, merged overdubs, physical button gestures and a live threshold meter. Compatible with Mac 0.6.0+ and phone 0.9.0+. Loops are lost on power-off. Threshold, level and duration apply live; Save looper settings stores them after the loop is cleared. New loop settings default to −50 dB and 100% level; lower levels remain adjustable. These new starter presets pass offline checks; this exact combined release still needs hardware testing.
