Install on Mac

  1. Download mighty-nam 0.6.0 and open the disk image.
  2. Drag mighty-nam.app into Applications, then launch it.
  3. Connect the Mighty Plug Pro with a USB data cable in normal mode. Close other controllers using the plug.

Universal Intel/Apple silicon preview; declares macOS 10.15+. It is ad-hoc signed and not notarized. If macOS blocks it, follow Apple’s Open Anyway instructions only if you trust the download. Keep Gatekeeper enabled. Changing from a privately signed build may require signing in to TONE3000 again.

The app installer does not install firmware or change system audio. Check the release checksum.

Choose a capture

Select NAM → Explore TONE3000. Sign in on TONE3000, browse the catalog and select a tone. The app validates its A2 Lite component, transfers it, then marks it active after confirmation. The official browser stays open so you can choose another capture.

An A2 download must contain a compatible Lite component; only that component runs. Full A2 is not supported. Amp-and-cab captures bypass the separate cabinet; amp-head captures can use a cabinet block. Favorites and onboard saves are separate. Creator attribution and capture license stay with the download.

Select the NAM block to adjust Input, Output, Bass, Middle, Treble and Mix. Input changes how hard you drive the capture; Output sets its level afterward. Save to plug stores these controls with the selected color.

Edit the chain

Add a block, drag it into place, then select it for controls. Its symbol and Enabled / Bypassed badge toggle processing. Bypass keeps the tile; Remove takes it out of the chain. Change block selects another available engine.

Stock effects remain available. FX A and FX B each offer Pitch, Auto Wah and modulation choices. Pitch spans −12 to +12 semitones and is intended for single notes. High / Low Cut has independent sliders. NAMLNK21+ also provide NAM input/output gain, bass/middle/treble and mix, plus a separate USB recording gain.

Pitch & octave

  1. Add or select FX A or FX B, then choose Pitch.
  2. Set Pitch from −12 to +12 semitones. −12 is an octave down; +12 is an octave up.
  3. Use Mix for dry/shifted balance. 100% gives the shifted signal; a lower mix blends in your original note.
  4. Drag the block to the position you want, then Save to plug to retain it.

Designed for single-note playing. Chords and fast transients can still produce artifacts; this is not a polyphonic pitch shifter.

Improved Auto Wah

  1. Select Auto Wah in FX A or FX B and enable the block.
  2. Place it before NAM for the wah to feed the capture, or after NAM for a different response.
  3. Adjust Sensitivity while playing soft and hard notes, then Resonance for emphasis and Mix for the wet/dry balance.
  4. Save to plug when the response feels right.

NAMLNK28 uses the newer Daisy-derived wah engine. The retained stock Touch Wah is also available under Drive.

Save to a color

Use one to seven colors. Choose an empty color to start from your current capture, or load a different capture and edit the effects. Save to plug stores that color’s capture, name, order, bypass states and controls. The app verifies readback. Unsaved edits are not guaranteed after switching or restarting. PRESET cycles occupied colors; both controllers can select a nonadjacent color directly.

NAMLNK18+ keeps the 8/16/32-sample output buffer globally across all colors. It does not change the 48 kHz sample rate or measure total latency. Saved presets are intended to play without a controller after power-on.

Build and install firmware

Required source file: MP3_OR_V3.0.5.bin — Mighty Plug Pro V3.0.5 Original. Select this extracted file in the builder. The ZIP, ChopTones image and other versions are not accepted.

  1. Download the official NUX V3.0.5 macOS ZIP, or find it under Support → Firmwares on the NUX product page.
  2. Unzip it. Keep MP3_OR_V3.0.5.bin (Original) and install NUX Device Updater from the included NUX Device Updater 2.2.1.dmg. The ChopTones file is not supported.
  3. Open the NAMLNK28 local builder, select MP3_OR_V3.0.5.bin and build. Save the generated firmware and build report. Your NUX file is not uploaded.
  4. Follow the installation steps: headphones unplugged, USB connected, PRESET held while powering on for blinking-blue mode. In NUX Device Updater, choose the generated file and Start Update. Wait for explicit success, then restart with POWER only.
  5. Reconnect either controller in normal mode. Three MIT-licensed RiffSmith presets are ready in Green, Orange and Red. Start with headphone volume low. Save your own captures and chains into any color.
Installation replaces onboard presets.

Preserve any presets you want to keep before updating. The app’s Settings → Set up firmware opens these same resources. Neither the Mac installer nor the builder flashes the plug automatically.

The locally generated image contains your NUX firmware and is not wholly MIT licensed. Keep it local. Experimental software; test coverage and known limits.

Record a loop

  1. Open Looper in the Mac or phone controller. Choose 30 seconds for the wider-bandwidth mode, or 60 seconds for a longer loop with reduced bandwidth.
  2. Start with the −50 dB threshold. Play a note and watch the input meter on the threshold slider. Set the threshold above idle noise and below the level of the notes that should start recording.
  3. Tap Arm. The preset light flashes while waiting; playing above the threshold starts recording.
  4. Press PRESET once, or use the controller’s finish control, to mark the end and repeat the loop.
  5. Tap POWER once to use the preset controls while your loop keeps playing. Change color and play another sound over it. Tap POWER once again to return to looper controls.
  6. With an existing loop, hold PRESET to start overdubbing; hold again to finish overdubbing. Layers merge into the loop; there is no separate undo.

Loop level starts at 100%. Lower it in either controller if desired. Threshold, level and duration apply live. To retain those settings after shutdown, clear the loop and choose Save looper settings. The audio loop itself is held in RAM and is lost on power-off.

Live preset changes keep the recorded loop’s original sound. Clear the loop before writing presets or looper settings to flash. See the full button table below for pause, resume, clear and exit.

Older NAMLNK26/27 gestures

Those builds use hold PRESET to clear in Looper, and hold PRESET to reverse preset cycling outside Looper. They cannot save loop settings. Use their controller help when running those versions.

Troubleshooting

No device: check the USB data cable, normal mode and competing controllers. Quiet Logic input: check input selection and USB recording gain; the NAMLNK23 duplex path still needs physical verification. A timing fault or failed transfer is not a reason to force playback on.

When filing an issue, include versions, mode and reproduction steps. Remove personal names, tokens, captures and device identifiers. Report an issue.
