MIGHTY PLUG PRO · A2 LITE · 48 KHZ

Mac & firmware

Set up the editor, keep your presets, and know which parts are experimental.

Install on Mac

  1. Download mighty-nam 0.5.2 and open the disk image.
  2. Drag mighty-nam.app into Applications, then launch it.
  3. Connect the Mighty Plug Pro with a USB data cable in normal mode. Close other controllers using the plug.

Universal Intel/Apple silicon preview; declares macOS 10.15+. It is ad-hoc signed and not notarized. If macOS blocks it, follow Apple’s Open Anyway instructions only if you trust the download. Keep Gatekeeper enabled. Changing from a privately signed build may require signing in to TONE3000 again.

The app installer does not install firmware or change system audio. Check the release checksum.

Choose a capture

Select NAM → Explore TONE3000. Sign in on TONE3000, browse the catalog and select a tone. The app validates its A2 Lite component, transfers it, then marks it active after confirmation. The official browser stays open so you can choose another capture.

Full A2 is not supported. Amp-and-cab captures bypass the separate cabinet; amp-head captures can use a cabinet block. Favorites and onboard saves are separate. Creator attribution and capture license stay with the download.

Edit the chain

Add a block, drag it into place, then select it for controls. Its symbol and Enabled / Bypassed badge toggle processing. Bypass keeps the tile; Remove takes it out of the chain. Change block selects another available engine.

Stock effects remain available. FX A and FX B each offer Pitch, Auto Wah and modulation choices. Pitch spans −12 to +12 semitones and is intended for single notes. High / Low Cut has independent sliders. NAMLNK21/22 also provide NAM input/output gain, bass/middle/treble and mix, plus a separate USB recording gain.

Save to a color

Choose a color, load a capture and edit the effects. Save to plug stores that color’s capture, name, order, bypass states and controls. The app verifies readback. Unsaved edits are not guaranteed after switching or restarting. PRESET cycles occupied colors; both controllers can select a nonadjacent color directly.

NAMLNK18+ keeps the 8/16/32-sample output buffer globally across all colors. It does not change the 48 kHz sample rate or measure total latency. Saved presets are intended to play without a controller after power-on.

Firmware is a separate step

There is no downloadable stock-based firmware image here. NUX bytes and captures are not ours to redistribute. Build locally from the exact stock package you are entitled to use, using the development instructions. The current owner-specific NAMLNK22 package embeds that owner’s Mac-saved presets; it is not a public factory bank.

  1. Match the hardware model, stock input and generated file hash. Read its preset replacement behavior.
  2. Keep USB connected and headphones unplugged. Power off, hold PRESET, then power on to enter blinking-blue update mode.
  3. Use the official NUX updater with the exact locally built file. Wait for explicit success before touching POWER or RESET.
  4. Restart with POWER only. Verify identity, presets and timing before listening at low plug volume.
Recovery is not guaranteed.

No complete bootloader backup exists. A stock restore depends on the updater remaining reachable. The tested behavior of one build is not proof of recovery from arbitrary firmware damage.

Troubleshooting

No device: check the USB data cable, normal mode and competing controllers. Quiet Logic input: check input selection and USB recording gain; the NAMLNK22 duplex repair still needs physical verification. A timing fault or failed transfer is not a reason to force playback on.

When filing an issue, include versions, mode and reproduction steps. Remove personal names, tokens, captures and device identifiers. Report an issue.
