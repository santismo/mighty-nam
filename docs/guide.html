01 / INSTALL

Start with the Mac app.

The preview supports Intel and Apple silicon in one download. The app declares macOS 10.15 or later; the full range of Mac hardware and OS versions has not been tested.

  1. Download and open the installer.

    Download mighty-nam 0.5 for Mac, then double-click the disk image.

  2. Drag mighty-nam to Applications.

    Use the Applications shortcut in the installer. Launch mighty-nam from Applications, then eject the disk image.

  3. Connect the plug in normal mode.

    Use a data-capable USB cable. Leave headphones unplugged for the first connection check. NAM device control requires compatible custom firmware; the Mac installer does not install it.

macOS says the developer cannot be verified

This preview is development signed and is not Apple notarized. After attempting to open it, use System Settings → Privacy & Security → Open Anyway if you choose to trust this release. Older macOS uses System Preferences. Keep Gatekeeper enabled globally. Apple’s instructions ↗

You can instead inspect the source and build locally. Release checksums are provided on the download page.

What this installer does

Installs the controller app by copying it to Applications. It does not flash the plug, install drivers, open an audio stream, or change your Mac’s system volume.

02 / CONNECT

Check the connection.

Use normal mode to edit and transfer models. Blinking-blue mode is for the official firmware updater. A successful USB connection alone does not mean stock firmware can run NAM.

Check the app’s device identity and model status before making changes. Keep output muted during model transfers and initial checks. For listening, plug headphones into the Mighty Plug and start with its volume at minimum, then raise it slowly.

The app cannot see my plug

Check that the cable carries data, the plug is powered on, and it is in normal mode. Close another MIDI controller if it is using the device. Reconnect and inspect the device status again. Do not enter update mode just to browse captures.

03 / CAPTURES

Find your sound.

  1. Select the NAM block.

    Open Explore TONE3000 and sign in in the browser window. Return to the controller after authentication.

  2. Choose a compatible capture.

    The plug engine accepts the supported 48 kHz A2 Lite architecture. A listing’s name or popularity is not proof of compatibility; the app validates the model before transfer.

  3. Load it and make it a favorite.

    Selecting a capture makes it the active NAM choice in the editor. When connected to compatible firmware, confirm the transfer completes and check the device status. Use the star to keep it in Favorites; favorites and the active capture are separate.

A full amp-and-cab capture bypasses the separate stock cabinet block. For an amp-head capture, choose a suitable cabinet in the chain. Your TONE3000 session is stored in the Mac’s Keychain; captures remain subject to their creators’ licenses.

Does the website connect to my plug?

No. This site is documentation, and its signal-chain example is an illustration. Use the installed Mac controller for sign-in, model transfers, and device control.

04 / SIGNAL CHAIN

Everything in its place.

Drag blocks to change their order. Select a block to show its controls below the chain. Click its block symbol to enable or bypass it. Effect selectors scroll within a bounded list so you can leave the picker without losing your place.

Gate, compressor, drive, cabinet, EQ, modulation, delay, and reverb retain the stock processing. NAM adds capture selection and gain/mix/tone controls. Heavy effect combinations can still reach the processing guard; there is no guarantee that every maximum setting is real-time safe.

Buffer and latency

NAMLNK09/10 add 8, 16, and 32-sample output staging at 48 kHz. Eight samples is the minimum and matches NAMLNK08. Larger values add staging delay; they do not give NAM more CPU time. These are not end-to-end latency measurements. Lower sample-rate operation is not implemented.

05 / PRESETS

Keep the capture with the color.

GreenOrangeRedBlueCyanPinkLilac

Choose a color, select a capture, set the effects and order, then choose Save [color] to plug. Each slot includes its capture, name, effect settings and bypasses, order, and output buffer. Unsaved edits remain Mac drafts.

The app verifies the save with a separate readback. The device is designed to cycle occupied colors with PRESET and skip empty slots. Saved presets are designed to start without the Mac after power-on. Uploading and saving mute output.

NAMLNK10 hardware trial pending

Seven-slot persistence is implemented and tested in simulation. Actual power-off retention, flash writes, physical LEDs/button behavior, and recovery still need to be verified on the plug. First installation starts empty and muted. Firmware reinstall/update currently clears the bank; retain your Mac library and re-save afterward.

06 / FIRMWARE

Know exactly what you’re installing.

The public download installs the app only. Current firmware is a hybrid built on exact stock NUX bytes. Those proprietary images are not distributed here. Developers can build a candidate locally from their own exact stock package.

  1. Match the model and the build.

    This work targets Mighty Plug Pro / MP-3. Check the candidate hash, matching stock restore image, and current validation status. Do not substitute another NUX model or stock version.

  2. Enter the official updater mode.

    With USB connected and headphones unplugged, power off normally. Hold PRESET while powering on to enter blinking-blue mode. Use the official NUX Device Updater.

  3. Wait for explicit success.

    Select the exact locally generated candidate. Do not unplug, reset, or switch power while updating. Only after the updater reports success, restart using POWER alone, without PRESET.

  4. Verify before listening.

    Confirm the firmware identity, mute state, USB response, model transfer, and preset readback. For NAMLNK10, verify standalone power-off recall and all seven colors with the Mac app closed before treating persistence as proven.

Recovery has limits.

No full bootloader backup exists. Stock firmware can restore the application only while the updater remains reachable. NAMLNK10 recovery is not yet physically verified, and arbitrary firmware damage may not be recoverable over USB.

07 / HELP

Leave a useful trail.

When reporting an issue, include the app version, exact firmware identity, Mac type, connection mode, and steps to reproduce it. Describe what you heard separately from device counters or emulator results. Remove personal account data, tokens, captures, and serial numbers.
