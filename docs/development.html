Repositories

mighty-nam contains the Mac app, firmware experiments, protocols and evidence. mighty-nam-controller contains the static phone page.

Both are public. Neither includes stock firmware, creator capture bundles, account tokens or private keys. Historical internal schema/storage identifiers remain stable for compatibility.

Mac and phone

Follow DEVELOPMENT.md for the pinned toolchain and build commands. Run Flutter/shared API tests before packaging. The public preview uses ad-hoc signing to avoid publishing a personal signing certificate; it is not notarized.

The phone controller is plain HTML/CSS/JavaScript, served over HTTPS. Run npm test. Independently distributed forks should register their own TONE3000 application and callback destinations.

Firmware

The current hybrid patches exact stock bytes locally and inserts original A2 Lite DSP and controller hooks. Use only the documented stock version and the build-specific validation gates. Do not upload the resulting hybrid image or a personal capture bank.
