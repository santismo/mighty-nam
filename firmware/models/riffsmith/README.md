# RiffSmith starter captures

Copyright (c) 2026 Matt Hartman. MIT; see LICENSE.

These three files are unchanged from the pinned upstream revision in
provenance.json. The author explicitly includes all four RiffSmith captures
in the repository MIT license in its “Credits and licenses” section and
states they were trained on his own rigs. Obtained directly from the
creator’s GitHub repository, not from the TONE3000 catalog/API.

mighty-nam uses only the 48 kHz, 3-channel A2 Lite component. The Original
files contain both Lite and Full models; Full is not loaded on the plug.
Green uses Clean; Orange uses Bass Clean; Red uses Distorted. All include
a cabinet in the capture metadata, so the separate stock cabinet is bypassed.
These are alternatives, not copies of the owner's personal captures.

The generated factory bank and bundled model library retain attribution.
No endorsement or sound-equivalence claim is made.
